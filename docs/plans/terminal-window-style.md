# 터미널 스타일 코드 창 적용 계획

**목표**

첨부한 참조의 중립 배경과 창 장식 색을 라이브 캔버스와 이미지 출력에 적용한다. [FR-STYLE-01·04](../product/PRD.md#43-이미지-스타일-fr-style)

- [x] 다크 테마 코드 창에는 `#1e1e1e` 본문과 `#252525` 제목 막대를 적용한다. 라이트 테마 제목 막대는 `#f1f1f1`로 맞춘다. 창 장식의 색과 위치를 라이브 창과 SVG에서 공유한다.
- [x] CSS와 SVG에서 창 바깥 테두리와 제목 막대 구분선을 제거한다. 스냅샷 좌표와 너비 계산에서 테두리 여백을 제거하고 창의 세로 치수를 유지한다.
- [x] 제목 편집, 줄 번호, 외부 투명도와 창 배경의 불투명도를 확인한다. PNG·SVG·JPG·WebP 및 PNG 클립보드 출력을 검증한다.

**검증 결과**

- `npm run typecheck` 통과, `npm run test -- --maxWorkers=2` 152개 통과.
- `npm run test:browser -- --project=chromium --workers=2` 84개 통과. 프로덕션 빌드, 네 형식의 다운로드와 PNG 복사, 창과 제목 막대의 색 및 투명 모서리를 확인했다.
- 로컬 Chrome에서 다크·라이트 코드 창을 캡처해 색상과 테두리 제거를 확인했다.
